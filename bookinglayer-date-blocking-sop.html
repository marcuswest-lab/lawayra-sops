SOP — Blocking Retreat Dates on Airbnb & Booking.com

Use this every time a retreat is scheduled, so OTA guests cannot book accommodations during the retreat dates.

What this SOP does: Creates an Availability Rule in BookingLayer's Channex inventory that closes out specific dates on Airbnb and Booking.com — without affecting BookingLayer's internal calendar. Retreat guests can still be booked directly. OTA guests cannot book those dates.

When to use this

  • A retreat is scheduled and you want to take cabins/dorms off Airbnb + Booking.com
  • A private group buyout where the venue is reserved but no OTA bookings should come in
  • Maintenance dates where rooms exist in BookingLayer but should not be sold via OTAs

Step-by-Step

Step 1 — Open the Availability Rules screen

  1. Log into BookingLayer: app.bookinglayer.io
  2. Left sidebar → Settings → Integrations (or navigate via the Channex link).
  3. Open Channex.
  4. Click on the location "LaWayra" → click Inventory.
  5. Look for the "Availability Rules" section / tab.

Step 2 — Create a new rule

  1. Click "Create" (or the + button).
  2. A pop-up appears titled "Create Availability Rule".

Step 3 — Fill in the rule

FieldWhat to put
Title Name the rule so you can find it later. Example: Retreat — June 10-17 cohort or Sarah's August Retreat
Affected Dates Start date = first night of the retreat
End date = last night of the retreat (NOT checkout day)
Example: Retreat runs June 10 → June 17 (guests check out the 17th). Set dates: June 10 → June 16.
Days of week Leave ALL days checked (Mo, Tu, We, Th, Fr, Sa, Su). The block should cover every day in the range.
Type Close Out
Affected Channels Check both:
☑ BookingCom - Lawayra Ayahuasca Retreat
☑ LaWayra Airbnb Channel
(Or click "Select All Items" for both)
Affected Room Types Check all 4 room types if the full venue is reserved:
☑ Bed in 6-Bed Female Dormitory Room
☑ Private Cabin - 6
☑ Single Bed in 10-Bed Dormitory Room
☑ Twin Room with Mountain View

Or uncheck rooms that ARE still available during the retreat (rare).

Step 4 — Save

  1. Click the blue "Save" button at the bottom.
  2. The rule appears in the Availability Rules list.

Step 5 — Verify the block reached the OTAs

Wait 5–10 minutes, then check:

  1. Booking.com: Open the Booking.com extranet → Calendar & Pricing → the retreat dates should now show as "Closed" / unavailable.
  2. Airbnb: Open the Airbnb host calendar for each listing → retreat dates should show as blocked (gray, not pink/green).
If both OTAs show the dates as blocked: done. Retreat guests can be booked into rooms directly in BookingLayer, and no OTA tourists can claim those dates.
If the OTAs still show dates as available after 15 minutes: the rule didn't push. Check BookingLayer → Integrations → Channex → activity log. Try editing the rule and saving again. If still broken, escalate.

How to REMOVE a block

If a retreat is cancelled or the dates change:

  1. Open BookingLayer → Channex → Inventory → Availability Rules.
  2. Find the rule by title.
  3. Either:
    • Edit the rule (change dates, channels, or rooms), then Save.
    • Delete the rule (use the Trash icon).
  4. Wait 5–10 minutes. The OTAs will reopen those dates automatically.

Important Rules

  • ✅ Always block in BookingLayer's Availability Rules. Never edit Airbnb or Booking.com calendars directly — Channex will overwrite manual blocks on the next sync.
  • ✅ Create the rule as soon as a retreat is confirmed — don't wait until the week of. The longer the buffer, the safer.
  • ✅ One rule per retreat. Naming convention: Retreat — [Month Day-Day] [cohort name]. Makes it easy to find and remove later.
  • ❌ Do NOT use this for individual room blocks. If only 1 cabin needs to be off-market for maintenance, use BookingLayer Planning → "Out of Service" booking instead. Availability Rules are for full-venue or multi-room blocks.
  • ❌ Do NOT check "Close Out" on the wrong dates. Double-check the date range before saving — guests already booked won't be cancelled, but new direct-BookingLayer bookings will also be blocked on those days.

Quick Reference

SituationWhat to do
New retreat confirmed Create Availability Rule with retreat dates + all rooms + both channels
Retreat date moved by one day Edit the existing rule, update dates, save
Retreat cancelled Delete the rule
Only Private Cabins are reserved; dorms still open Create rule with dates + uncheck dormitory room types
Need to block just one cabin for maintenance Use BookingLayer Planning → Out of Service booking (NOT Availability Rule)
Golden rule: When a retreat is scheduled, create the Availability Rule first. Then book the retreat guests into BookingLayer normally. The two systems stay separate but the OTAs stay closed.
